> **Live:** [vetman.ng](https://vetman.ng) &nbsp;|&nbsp; **Sector:** Veterinary & Agriculture &nbsp;|&nbsp; **Reach:** Global

A comprehensive multi-module SaaS platform for veterinary clinics worldwide — covering all animal species and every clinic workflow from patient records to poultry bookings.

| Module | Key Features | Tech |
|---|---|---|
| 🩺 **Treatment** | Diagnosis-based billing, automated cost calculation, patient history, pet travel certificates | ASP.NET Core + EF Core |

| 🛒 **Point of Sale (POS)** | Track sales, inventory, accept cash/card, integrated with treatment data | Bootstrap + jQuery |
| 📋 **Patient Records** | Full medical history, disease tracking, client-patient linking, appointment reminders | Web API + SQL Server |
| 📊 **Reports & Analytics** | Profit tracking, visit counters, SMS reminder logs, multi-clinic dashboard | Custom JS + API |
| 👥 **Multi-role Access** | Admin / Manager / Staff role-based dashboards per company | ASP.NET Identity |

**Highlights:**
- 📱 Automated SMS & email reminders to keep clients loyal and reduce missed appointments
- 🔒 reCAPTCHA, GDPR-aware architecture, multi-company tenancy
- 📈 Google Analytics + real-time live API usage tracking via custom JS
- 🌍 Serving **100+ vet clinics** globally
